Sauvegarder mon journal

Le journal est enregistré sur cet appareil. Garde une copie séparée pour le retrouver si tu changes d’iPhone ou si Safari efface ses données.

Sur iPhone, choisis Enregistrer dans Fichiers, puis iCloud Drive. Le fichier contient ton journal et ton profil.

Configurer la sauvegarde

Sur GitHub, choisis Only select repositories, puis le dépôt privé assiette-sauvegarde. Vérifie que Contents est en Read and write. Garde ton mot de passe de sauvegarde dans ton gestionnaire de mots de passe pour restaurer le journal sur un autre iPhone.
